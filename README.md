# Quick C V

Dead simple local-network sync for text, images, and videos.

Run one tiny server on a Mac, open its LAN URL on every device, enter the same channel passcode, and everything in that channel stays in sync. No accounts, no cloud service, no build step.

## Requirements

- Node.js 24 or newer
- npm

## Features

- Instant shared text editing over WebSockets
- Image and video uploads synced to every connected device in the same channel
- SQLite persistence for text and media metadata
- Local file storage for uploads
- One-command URL discovery with `quickcv urls`
- Code-only access model: anyone with the passcode can view and edit

## Quick Start

```sh
git clone https://github.com/yuleisheng/quick-c-v.git
cd quick-c-v
npm install
npm start
```

The server prints URLs like:

```txt
Quick C V is running at http://localhost:3000
Open this on other devices on the same network:
  http://192.168.1.42:3000
```

Open the LAN URL on phones, tablets, or other computers connected to the same network.

## Commands

```sh
npm start
```

Start the local server.

```sh
npm run urls
```

Print localhost and LAN URLs again. The command uses the last port the server started on.

```sh
npm test
```

Run the smoke test for passcode validation, text sync, image upload, video upload, WebSocket broadcast, and restart persistence.

If you link the package locally, you can call the URL helper directly:

```sh
npm link
quickcv urls
quickcv urls --port 3001
```

## How To Use

1. Start the server on one Mac.
2. Open the printed LAN URL on every device.
3. Enter the same channel passcode on every device.
4. Type text or add media.

Everything is scoped to the passcode. Joining a new passcode creates that channel automatically.

## Storage

Runtime data is stored under `data/`:

- `data/sync.db` stores text and media metadata.
- `data/uploads/` stores uploaded image and video files.
- `data/server.json` stores the last server port for `quickcv urls`.

The `data/` directory is ignored by Git.

## Media

Uploads are limited to `100 MB` per file.

Supported image types:

- AVIF
- GIF
- HEIC / HEIF
- JPEG
- PNG
- WebP

Supported video types:

- MP4
- MPEG
- MOV / QuickTime
- WebM

## Security Model

Quick C V is designed for trusted local networks.

- There are no accounts or passwords beyond the channel passcode.
- Anyone who knows a passcode can view and edit that channel.
- Files are stored locally on the machine running the server.
- Uploaded filenames are generated by the server; original display names are stored as metadata.
- Uploads are restricted to an allowlist of image/video MIME types.
- The app sets basic hardening headers and serves uploads with `nosniff`.

Do not expose this server directly to the public internet without adding real authentication and stricter upload controls.

## Troubleshooting

If another device cannot open the LAN URL:

- Make sure both devices are on the same Wi-Fi/network.
- Try the `192.168.x.x` URL first if multiple URLs are printed.
- Allow incoming connections for Node if macOS asks.
- Temporarily disable VPNs or network filters that block local traffic.
- Use another port if `3000` is busy:

```sh
PORT=3001 npm start
npm run urls
```
